## 🔧 Quick Reference

<details>
<summary><strong>Core OOP Pillars</strong></summary>

| Pillar | Keyword | Meaning |
|--------|---------|---------|
| **Encapsulation** | `private` / `public` | Bundle data + methods; hide internals |
| **Abstraction** | Abstract classes | Expose only what's necessary |
| **Inheritance** | `: public Base` | Derive new classes from existing ones |
| **Polymorphism** | `virtual` | Same interface, different behavior |

</details>

<details>
<summary><strong>Exam Tips</strong></summary>

- 📝 Inheritance + Polymorphism questions appear almost **every year**
- ⚡ Know your **constructor/destructor** call order cold
- 🔁 Operator overloading — always check if `friend` function is needed
- 📁 File handling: know both **text** and **binary** modes
- 🧪 For lab exams, practice writing programs **from scratch** without reference

</details>
